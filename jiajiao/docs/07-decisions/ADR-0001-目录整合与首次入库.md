# ADR-0001 目录整合与首次入库

- **日期**：2026-09-30
- **状态**：已采纳

## 背景

源码以 `jiajiao-server/`、`jiajiao-web/` 两个平级目录放入多项目仓库根，未被 git 跟踪；仓库约定「一个项目一个子目录，前台后台同目录」。

## 决策

1. 整合为 `jiajiao/server` + `jiajiao/web`（内容搬迁，`jiajiao-server` 空壳因被会话占用暂留，会后可删）
2. `server/config/database*.php` 中卖家数据库凭据**原样入库**（用户决策：私仓可接受；后续部署自有环境前替换，替换时不得再硬编码）
3. `untime/`（复制残留错名目录）gitignore，不删除
4. 新增 `.gitignore`、`AGENTS.md`、`CONTEXT.md`、`docs/` 骨架；无独立 `.git`，随仓库根提交

## 后果

- git 历史中将永久保留卖家数据库凭据（私仓，已接受）
- 部署前必须处理凭据（改为 `.env` 方式）

## 修订（2026-09-30，推送被拦后）

GitHub Push Protection 拦截推送：检出 `config/my.php` 中卖家**阿里云 AccessKey**（短信 ID/Secret + OSS Secret）。经用户确认（询问「是否影响部署」后采纳脱敏方案），将 my.php 中**全部 7 处卖家云密钥**（阿里云短信 ID/Secret、阿里云 OSS ID/Secret、七牛云 Key/Secret、极速短信 key）置空；原值存入 gitignore 的 `server/config/secrets.local.md`，部署时填自有密钥即可，不影响部署。数据库密码未被 GitHub 拦截，仍按原样入库。
