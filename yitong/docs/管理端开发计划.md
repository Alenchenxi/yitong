# 燚桐管理端开发计划

> 本文记录管理端（小程序内管理员角色页）对标商家端后的系统化重构范围。后续管理端开发以本文为专项计划，同时遵守 `docs/功能规划.md`、`docs/任务规划.md`、`docs/UI设计规范.md` 和 `docs/开发记录/分支开发计划.md`。
> 背景：2026-07-09 三端合一后，管理功能在 `apps/user-miniprogram/pages/admin/` 以管理员角色页承载，无独立 admin-web。后端 30+ 接口已就绪，本专项聚焦前端结构重构与 UI 统一，不新增功能、不动后端。

## 0. 范围原则

- 管理端是燚桐平台的一部分，视觉统一主色 `#F9C801`，遵守 `docs/UI设计规范.md` §8.3（克制、表格筛选批量为主、统一状态色）。
- 管理端保留五个主入口（自定义底部 tab）：看板、审核、运营、用户、我的。
- 本次为纯前端重构 + 计划文档落地，不动后端 / schema / `.env` / 其他端代码。
- 不新增功能，只把现有 12-tab 单页重组为 5 页 + 统一 UI 规范。

## 1. 明确不做项

- 不做独立 admin-web（三端合一已取消，`apps/admin-web` 空壳已清理）。
- 不新增后端接口（现有 30+ 接口复用）。
- 不做 AI、礼物、打赏、视频、实时语音房等已排除能力的视觉占位。
- 不做管理端独立频道色（不再用粉色/蓝色/绿色做管理端主色）。
- 不做付费装扮、虚拟币、邮件通知、第三方客服/开票/实名。

## 2. 当前实现基线

后端（`apps/server/src/modules/admin/`）：`AdminController` 暴露 30+ 端点，覆盖审核队列 / 看板 / 举报 / 商家审核 / 帖子下架置顶加精 / 匿名帖 / 工单 / 用户封禁禁言 / 单价 / 树洞标签 / 活动专题 / 话题 / 评论管理 / 岗位精品，统一 `@AdminGuard`。

前端（`apps/user-miniprogram/pages/admin/`）：

- `index` 单页 12 tab（queue/stats/pricing/announce/reports/tickets/users/activity/topic/tags/jobs/comments），功能全但结构挤；wxss 用粉色 `#ff4d6d` + 绿色 `#52c41a`，违反 UI 规范主色 `#F9C801`；状态用纯文本无状态色标签。
- `profile` 页裸（仅昵称 + 退出）。

主要缺口：

- 12 tab 横滚难导航，需拆成多页。
- wxss 用 `#ff4d6d`/`#52c41a`，需统一到 `#F9C801` + 状态色。
- 状态纯文本，需状态色标签。
- `profile` 裸，需对标商家 profile 工作台化。
- 缺独立计划文档（本文件补齐）。

## 3. 目标结构：12-tab 单页 -> 5 页 + 自定义 `<bottom-tab>`

对标商家端 5 tab 结构。复用 `services/admin.ts` 全部函数（无新增 API）与 `components/bottom-tab`。

| 底部 tab | 页面 | 承载原 tab | 内部 sub-tab |
| --- | --- | --- | --- |
| 看板 | `pages/admin/dashboard/index` | stats | 总览 / 今日 / 7 天趋势 + 待办聚合 + 快捷入口（落地页） |
| 审核 | `pages/admin/review/index` | queue + reports + comments | 商家入驻 / 表白墙帖(下架·置顶·加精) / 树洞帖 / 评论置顶 / 举报处理 |
| 运营 | `pages/admin/ops/index` | announce + activity + topic + tags + jobs + pricing | 公告 / 活动专题 / 话题 / 树洞标签 / 岗位精品 / 单价 |
| 用户 | `pages/admin/users/index` | users + tickets | 用户(封禁·禁言) / 工单处理 |
| 我的 | `pages/admin/profile/index`（重构） | profile | 管理员资料卡 + 快捷入口 + 设置 + 退出 |
