## 5. P3-05 权限与匿名隔离复核

### 5.1 实名（User）

- JWT token 含 `role`（user/merchant/admin）+ `uid` + `type=access|refresh`。
- `@UseGuards(JwtAuthGuard)` 全局 APP_GUARD，未登录 10001。
- `@UseGuards(AdminGuard)` 管理员接口校验 `role === ADMIN`，否则 10003。
- 商家接口在 service 内 `assertOwnsPost(uid, postId)` 校验资源归属。
- 跨用户读取：我的报名/简历/草稿/收藏等均按 `uid` 过滤。

### 5.2 树洞匿名（AnonProfile + AnonGroup + ChatMessage）

| 表 | 是否含真实 uid | 隔离手段 |
| --- | --- | --- |
| `AnonymousProfile` | 含 userId（后台可追溯） | 前端只回 anonId + nickname/avatar |
| `AnonymousPost` | 含 authorId（uid） | 实名帖正常；匿名帖 authorId 传空 + anonName |
| `AnonBlock` | 仅 anonId | 屏蔽后：匹配关闭 + 聊天 + 广场均按 anonId 隔离 |
| `ChatMatch` | 仅 anonId（anonIdA/B） | 匹配关系按 anonId |
| `ChatMessage.groupId/toId/fromId` | 全部用 anonId | 群消息无真实 uid |
| `AnonGroup` | ownerAnonId | 群主/管理员/成员均 anonId |
| `AnonGroupMember` | anonId + role + mutedUntil | 群成员表无 uid |
| `AnonGroupJoinRequest` | anonId + reviewedBy(anonId) | 申请审核也用 anonId |

✅ **红线未破**：树洞相关表（除 AnonymousProfile 后台可追溯字段）零真实 uid。前端展示仅 anonId + nickname/avatar。AnnonGuard 校验 anonToken。

### 5.3 兼职支付

- 服务端 `PricingConfig` 单价，订单 `amount = pricing.price`，**不信前端传入金额**（已严格）。
- 支付回调 `notify` 验签（dev mock 直达；prod 需 WX_PAY_API_V3_KEY 验签）。
