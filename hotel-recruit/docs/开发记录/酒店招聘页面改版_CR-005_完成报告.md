## 问题与决策

### git-bash curl 中文 body 转码

**情况**：curl `-d` 内联中文 JSON 在 MSYS 下被转码，服务端收到乱码报「请选择性别」。
**处理**：冒烟改用 `node -e` + 全局 fetch 发请求，UTF-8 无损。
**影响**：后续本仓库接口冒烟统一用 node fetch，不用 curl 内联中文。

### node --test 带目录参数会失败

**情况**：`node --test test/` 解析为 1 个失败用例（Windows/MSYS 下参数处理差异）。
**处理**：统一用 `node --test`（默认发现 test/ 目录），已写进 CR-005 任务计划。
**影响**：无。
