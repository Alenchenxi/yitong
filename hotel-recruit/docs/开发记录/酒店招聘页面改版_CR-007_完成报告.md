## 问题与决策

### Edge 无头小窗口渲染异常

**情况**：`--window-size=414,896` 时页面视口量出 0 宽、截图白屏；320px 时视口被量成 300px。
**处理**：改用正常桌面窗口（700×900），由探针页的 iframe 属性控制内嵌页宽度（`f.width='414'`；之前写在 style.cssText 里的 width 不生效），并注入样式隐藏滚动条模拟手机可用宽度。
**影响**：已记入记忆（hotel-recruit-local-testing），下次验收直接用大窗口 + iframe 宽度的做法。

### 验收中两次触发报名限流

**情况**：本地限流每手机号 60s 内 3 次、每 IP 每小时 3 次，多轮验收后提交被 429。
**处理**：重启临时服务清内存限流后重跑。
**影响**：无。

### 探针页放 `public/` 临时副本，不进仓库

沿 CR-006 做法：探针页只存在于临时副本，验收后整个副本删除，仓库不含测试专用页面。
