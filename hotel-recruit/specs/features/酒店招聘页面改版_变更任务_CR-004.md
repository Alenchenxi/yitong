## 3. 新增验收标准

- **AC-015：报名成功弹窗展示酒店微信群码**
  - **Given** 访客提交报名成功（或更新报名成功），且 `public/qr/` 下存在当前报名酒店的群码图片（文件名与酒店名完全一致）
  - **When** 查看报名成功弹窗
  - **Then** 弹窗展示该酒店的微信群二维码及“长按识别二维码进群”提示；酒店暂无群码图片时不显示二维码行，弹窗其余内容不变

## 4. 增量任务

### [x] Task-CR004-01：成功弹窗新增酒店群码展示

**通俗解释**：报名成功后，弹窗里直接能看到这家酒店的微信群二维码，长按就能进群。

**做什么**：
1. `#okView` 内新增默认隐藏的二维码区块（`<img>` + “长按识别二维码，加入该酒店对接群”提示文案）。
2. 提交成功回调中按约定路径 `qr/<encodeURIComponent(currentHotel)>.jpg` 设置图片源：加载成功显示区块，失败保持隐藏（与相册“缺图占位”同思路，用 `onload/onerror` 切换）。
3. 新增二维码区块样式（约 180px 方图、圆角，风格与弹窗现有元素一致）。
4. AGENTS.md `public/img/` 说明行后补一行 `public/qr/` 群码目录约定。

**涉及文件**：`public/index.html`、`AGENTS.md`

**参考**：本文档 AC-015；需求文档 CR-004 变更日志

**依赖**：无

**预估工时**：30 分钟

**验证标准**（TDD RED 阶段依据）：
- [ ] `test/ui-contract.test.js` 新增用例：`okView` 内存在 `okQr` 图片元素与“长按识别”提示，且默认隐藏
- [ ] 成功回调按 `qr/<encodeURIComponent(酒店名)>.jpg` 设置图片源（静态断言可匹配 `qr/' + encodeURIComponent(currentHotel) + '.jpg`）
- [ ] 边界：图片 `onerror` 时二维码区块保持隐藏，弹窗标题/文案行为不变
