# 酒店招聘页面改版 — 变更记录 CR-001

## 1. 变更概览

**变更标题**：恢复推广员申请入口并增强海报按钮对比度  
**变更类型**：微调  
**变更原因**：普通访客需要有入口申请推广身份，推广员的海报按钮需要更清晰。  
**发起日期**：2026-10-28  
**关联功能**：酒店招聘页面改版

## 2. 影响分析

| 影响范围 | 变更内容 |
|---------|---------|
| 需求 | 修改 AC-009，新增 AC-012 |
| 页面 | 恢复普通访客可见的推广员申请入口 |
| 身份切换 | 注册成功或已有推广身份时隐藏申请入口，显示推广工具 |
| 样式 | 海报按钮改为深色背景配亮色文字 |

不修改推广员注册接口、推广码格式、30 天归因、海报生成或业绩统计逻辑。

## 3. 新增验收标准

- **AC-012：推广员申请入口转换**
  - **Given** 普通访客打开页面
  - **When** 完成推广员注册并获得推广码
  - **Then** 申请入口隐藏，页面显示高对比度的“生成推广海报”按钮和业绩入口

## 4. 增量任务

### [x] Task-CR001-01：恢复入口与身份转换

**做什么**：增加普通访客可见的申请入口，复用现有注册弹层，并在获得推广身份后切换为推广工具。

**涉及文件**：`public/index.html`

**验证标准**：
- 普通访客能看到并点击“申请成为推广员”。
- 普通访客看不到业绩和海报工具。
- 已有或新获得推广身份后，申请入口隐藏，推广工具出现。

### [x] Task-CR001-02：提升海报按钮对比度

**做什么**：将“生成推广海报”按钮调整为深绿背景和亮白文字。

**涉及文件**：`public/index.html`

**验证标准**：按钮文字在手机和桌面端均清晰可辨。

### [x] Task-CR001-03：回归验证

**做什么**：运行 UI 契约测试、前端语法检查和浏览器截图验收。

**验证标准**：
- 入口与身份切换测试通过。
- 推广员注册、海报和业绩入口原有代码仍可用。
- 页面无新的横向溢出或遮挡。

## 5. AC 覆盖总表

| AC 编号 | 操作 | 承接任务 | 验证方式 |
|---------|------|---------|---------|
| AC-009 | 修改 | Task-CR001-01 | 浏览器渲染 DOM |
| AC-012 | 新增 | Task-CR001-01, Task-CR001-02 | UI 契约测试与截图 |

## 6. 变更总结

**新增任务数**：3 个  
**风险等级**：低 — 仅修改页面入口和样式，不改接口与数据。
