## 3. 变更详情

### 新增/修改的验收标准

见需求文档 AC-016 至 AC-019（Given-When-Then）。

### 技术变更

- **后端拦截**（`src/app.js` `handleApply`，现 `src/app.js:309`）：
  ```js
  const cur = hotels.find(h => h.name === hotel);
  if (!cur) return sendJSON(res, 400, { ok: false, msg: '报名酒店无效，请返回重新报名' });
  if (cur.paused) return sendJSON(res, 400, { ok: false, msg: '该酒店已暂停报名，请选择其他酒店' });
  ```
- **前端按钮**：`makeCard` 中 `apply.textContent = h.paused ? '暂停报名' : '立即报名'; apply.disabled = !!h.paused;`；`openDetails` 中对 `detailApply` 同样处理（每次打开详情无条件重置，天然覆盖恢复场景）。
- **计数**：`renderCards` 的“共 N 家在招”与 `render` 的 heroBtn 文案均改为统计 `HOTELS.filter(h => !h.paused)`；酒店卡片列表本身不过滤，暂停酒店仍展示。
- 首屏薪资区间/标签（`heroFill`）保持包含暂停酒店：展示的是真实待遇数据，非“在招”口径。

### 兼容性说明

- 未配置 `paused` 的酒店行为与现状完全一致（`undefined` 为假值）。
- 暂停期间已提交的飞书记录不受影响；用户在表单打开期间配置暂停后提交，由 AC-019 后端拦截兜底。
