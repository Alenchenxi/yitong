# 酒店招聘页面改版 — 功能需求说明书

## 1. 背景与价值

**为什么做**：现有 20 家酒店以区域折叠长列表展示，实拍图利用不足，待遇信息集中在长文本里，求职者难以快速比较岗位；普通访客还会看到推广工具，报名页也缺少费用、年龄和隐私说明。

**做成什么样**：求职者可以按地区快速筛选、用实拍图和结构化条件比较酒店，并在明确了解报名规则后完成报名；推广员仍保留原有归因与海报能力。

## 2. 范围

### 本次做

- 地区筛选与结果计数，默认展示全部 20 家酒店。
- 横向实拍首图、结构化待遇信息、差异亮点和酒店详情弹层。
- 普通访客的报名流程、常见问题和咨询方式。
- 报名免费、最低年龄、隐私用途说明与提交确认。
- 保留真实报名数、手机号更新、首次推广归因和推广海报。

### 本次不做

- 改造飞书字段或报名数据结构。
- 增加岗位搜索、薪资排序或多条件组合筛选。
- 编造或代填尚未提供的公开联系电话。

## 3. 用户与故事

| 编号 | 用户故事 | 关联 AC |
|------|---------|---------|
| US-001 | 作为求职者，我想快速筛选并比较酒店，以便选出适合自己的岗位 | AC-001 至 AC-004 |
| US-002 | 作为求职者，我想在报名之前看清费用、年龄和信息用途，以便放心提交 | AC-005 至 AC-008 |
| US-003 | 作为推广员，我想继续使用专属链接和海报，以便维持推广归因 | AC-009, AC-010 |
| US-004 | 作为求职者，我想报名时多填一个备选酒店，以便首选满员时也能被安排 | AC-020 至 AC-024 |

## 4. 核心流程与业务规则

1. 访客进入页面，看到真实数据汇总和全部酒店岗位。
2. 访客按地区筛选，查看卡片亮点与酒店详情。
3. 访客选择酒店，阅读报名说明并填写表单。
4. 系统校验信息后提交；相同手机号再次提交时更新酒店，不改变首次推广归属；选填的备选酒店随报名一并写入，重复提交未填则清空。

- BR-001：首屏薪资、春节工资和报名人数只能来自真实数据。
- BR-002：普通访客可以看到“申请成为推广员”入口，但不显示推广业绩和推广海报工具；通过他人的推广链接进入只建立报名归因，不获得推广员身份。
- BR-003：最低报名年龄为 16 周岁，部分岗位可能要求 18 周岁，以酒店审核为准。
- BR-004：联系电话未配置时不得显示虚假号码。
- BR-005：备选酒店为选填，不得与报名酒店相同；重复提交未填即视为不再需要备选。

## 5. 验收标准

### 5.1 正常流程

- [ ] **AC-001：默认展示全部岗位**
  - **Given** 配置中存在 20 家酒店
  - **When** 访客打开页面
  - **Then** 地区筛选默认选中“全部”，页面显示 20 个岗位结果

- [ ] **AC-002：地区筛选**
  - **Given** 访客位于岗位列表
  - **When** 访客选择瑞安、鹿城、瓯海或其他
  - **Then** 页面只显示对应区域酒店，并同步显示准确数量

- [ ] **AC-003：结构化比较**
  - **Given** 任一酒店卡片可见
  - **When** 访客浏览卡片
  - **Then** 能直接看到日薪、工时、月休、春节工资和该酒店差异亮点

- [ ] **AC-004：查看酒店详情**
  - **Given** 酒店存在实拍照片和待遇信息
  - **When** 访客点击“查看详情”
  - **Then** 弹层展示最多 3 张实拍图，以及住宿、加班、车费、提成和地址等完整信息

- [ ] **AC-005：可信报名说明**
  - **Given** 普通访客浏览页面或报名表
  - **When** 查看报名说明
  - **Then** 页面明确显示不收取报名费、联系流程、最低年龄和信息用途

- [ ] **AC-006：报名提交**
  - **Given** 访客年满最低年龄且填写完整有效信息并确认报名说明
  - **When** 点击“确认并提交报名”
  - **Then** 页面提交现有报名接口并展示成功或更新结果

- [ ] **AC-015：报名成功弹窗展示酒店微信群码**
  - **Given** 访客提交报名成功（或更新报名成功），且 `public/qr/` 下存在当前报名酒店的群码图片（文件名与酒店名完全一致）
  - **When** 查看报名成功弹窗
  - **Then** 弹窗展示该酒店的微信群二维码及“长按识别二维码进群”提示；酒店暂无群码图片时不显示二维码行，弹窗其余内容不变

- [ ] **AC-016：暂停酒店的报名按钮置灰**
  - **Given** hotels.json 中某酒店配置了 `"paused": true` 并重启生效
  - **When** 访客打开页面查看该酒店卡片或其详情弹层
  - **Then** 卡片“立即报名”与详情弹层“报名这家酒店”按钮均为置灰不可点状态，文本显示“暂停报名”；酒店卡片其余内容（图片、待遇、地址）正常展示

- [ ] **AC-017：在招计数剔除暂停酒店**
  - **Given** 配置中存在暂停中的酒店
  - **When** 访客打开页面
  - **Then** “共 N 家在招”与首屏“查看 N 家在招酒店”的计数不包含暂停中的酒店

- [ ] **AC-018：恢复报名后入口还原**
  - **Given** 某酒店此前配置了 `"paused": true`
  - **When** 从配置中移除该字段并重启生效后，访客打开页面
  - **Then** 该酒店按钮恢复为“立即报名”/“报名这家酒店”且可点击，在招计数恢复包含该酒店

- [ ] **AC-020：表单备选酒店与报名酒店联动**
  - **Given** 访客从某家酒店的报名入口打开报名表单
  - **When** 查看备选酒店下拉
  - **Then** 该项为选填且默认不选；选项不包含当前报名酒店和暂停报名的酒店；从另一家酒店进入时选项随之变化

- [ ] **AC-021：备选酒店随报名信息一次写入飞书**
  - **Given** 访客提交报名时选择了备选酒店
  - **When** 提交成功
  - **Then** 飞书对应行在同一次写入中带上「备选酒店」并填入该酒店名；该列不存在时先自动新增文本列，已存在则直接写入；已有历史记录该列保持为空

- [ ] **AC-022：重复提交未填备选时清空**
  - **Given** 某手机号此前的报名记录里已有备选酒店
  - **When** 该手机号重新提交报名且未填备选酒店
  - **Then** 飞书对应行的「备选酒店」被清空，其余字段按本次提交更新

### 5.2 边界与异常

- [ ] **AC-007：未达到最低年龄**
  - **Given** 出生年月对应年龄不足 16 周岁
  - **When** 访客提交报名
  - **Then** 页面阻止提交并明确提示最低年龄要求

- [ ] **AC-008：配置或网络异常**
  - **Given** 岗位接口加载失败或真实报名数接口失败
  - **When** 页面加载
  - **Then** 岗位区提示刷新重试；报名数失败时不显示虚假数字

- [ ] **AC-019：暂停酒店提交被后端拒绝**
  - **Given** 某酒店已暂停报名
  - **When** 有请求提交该酒店的报名（含绕过页面按钮直接调接口、或页面打开后配置才暂停的存量表单）
  - **Then** 接口拒绝并返回“已暂停报名”类明确提示，飞书不产生新记录

- [ ] **AC-023：无效备选酒店被拒绝**
  - **Given** 提交的备选酒店与报名酒店相同、不在酒店列表中或已暂停报名
  - **When** 提交报名
  - **Then** 接口拒绝并提示重新选择，飞书不产生任何写入

- [ ] **AC-024：备选列异常不影响报名**
  - **Given** 提交含备选酒店，且「备选酒店」列的存在性检查、新增或写入环节出错
  - **When** 提交报名
  - **Then** 报名信息仍正常写入并返回成功，备选酒店未写入时记录错误日志；首次报名未填备选时不触发任何列操作

### 5.3 业务规则验证

- [ ] **AC-009：普通访客不显示推广工具** ← BR-002
  - **Given** 访客没有本机推广员身份，包括通过他人的推广链接进入
  - **When** 打开页面
  - **Then** 页面显示“申请成为推广员”入口，但不显示业绩查询或推广海报按钮

- [ ] **AC-010：推广身份保留能力** ← BR-002
  - **Given** 访客已在本机完成推广员注册并保存自己的推广码
  - **When** 浏览页面
  - **Then** 页面显示推广工具、业绩入口和海报生成功能

- [ ] **AC-011：联系电话降级** ← BR-004
  - **Given** 配置中没有公开联系电话
  - **When** 页面渲染咨询区
  - **Then** 显示“报名后专员回电”，不渲染拨号链接或虚假号码

- [ ] **AC-012：推广员申请入口转换** ← BR-002
  - **Given** 普通访客打开页面
  - **When** 完成推广员注册并获得推广码
  - **Then** 申请入口隐藏，页面显示高对比度的“生成推广海报”按钮和业绩入口

- [ ] **AC-013：推广归因与本人身份分离** ← BR-002
  - **Given** 普通访客通过 `?inviter=p001` 进入页面
  - **When** 访客浏览岗位或提交报名
  - **Then** 页面保留“申请成为推广员”入口，报名归因仍使用 `p001`；若访客注册成为推广员，其海报使用新生成的本人推广码

- [ ] **AC-014：注册成功后的海报引导**
  - **Given** 访客已在当前页面完成推广员注册
  - **When** 查看注册成功弹窗
  - **Then** 弹窗明确提示无需重新打开专属链接，关闭弹窗后可直接在当前页面生成并保存本人专属海报

## 变更日志 (Change Log)

### CR-001: 恢复推广员申请入口并增强海报按钮对比度 (2026-10-28)

**变更类型**: 微调

**变更原因**: 普通访客需要明确入口申请成为推广员，推广员需要更醒目的海报生成按钮。

**变更内容**:
- 普通访客恢复“申请成为推广员”入口，但推广工具继续按身份控制。
- 注册成功后自动隐藏申请入口并显示推广工具。
- “生成推广海报”按钮改用亮色文字与高对比背景。

### CR-002: 分离推广归因与本人推广身份 (2026-10-28)

**变更类型**: 修正

**变更原因**: 非推广员通常通过他人的推广链接进入，地址栏中的 `inviter` 不能作为本人推广员身份。

**变更内容**:
- `inviter` 仅用于访问与报名归因。
- 新增本机 `promoter_self` 状态保存本人推广码。
- 通过推广链接进入的普通访客继续显示申请入口，不显示他人的推广工具。
- 注册成功后使用本人推广码生成链接和海报，不覆盖原报名归因。

### CR-003: 更新注册成功后的海报引导 (2026-10-28)

**变更类型**: 微调

**变更原因**: 注册完成后当前页面已具备本人推广码和海报能力，无需引导用户重新打开专属链接。

**变更内容**:
- 成功弹窗改为提示关闭弹窗后直接点击当前页面右下角生成专属海报。
- 删除“重新打开你的链接”这一过期操作步骤。

### CR-004: 报名成功弹窗展示当前酒店的微信群二维码 (2026-10-31)

**变更类型**: 扩展

**变更原因**: 报名成功后求职者需要加入酒店微信群对接入职事宜，弹窗直接展示对应酒店群码最省一步沟通。

**变更内容**:
- 报名成功 / 更新报名弹窗新增当前报名酒店的微信群二维码展示与“长按识别二维码进群”提示。
- 群码图片约定：`public/qr/<酒店名>.jpg`（文件名与酒店名完全一致），酒店未建群时不放图，弹窗自动隐藏二维码行。
- 后端与 hotels.json 零改动（`/api/config` 整包透传，前端按约定路径加载图片）。

### CR-005: 支持暂停/恢复单个酒店报名 (2026-11-24)

**变更类型**: 扩展

**变更原因**: 酒店招满或临时停招时需要停止收报名，恢复后页面入口自动还原。

**变更内容**:
- hotels.json 酒店对象新增可选 `paused` 字段：`true` 即暂停报名，移除或改 `false` 即恢复，`docker compose restart` 生效（沿用现有配置口径，不新增管理接口）。
- 暂停酒店的两个报名入口（卡片“立即报名”、详情弹层“报名这家酒店”）置灰（复用现有 `.btn[disabled]` 样式）、文本变“暂停报名”，酒店卡片本身仍展示。
- “共 N 家在招”与首屏“查看 N 家在招酒店”计数剔除暂停酒店。
- `/api/apply` 拒绝暂停酒店的提交（含绕过前端的直接请求），返回明确提示。
- 新增 AC-016 至 AC-019。

### CR-006: 报名表单新增选填的备选酒店并同步飞书 (2026-11-24)

**变更类型**: 扩展

**变更原因**: 首选酒店招满时需要第二个可安排的去向，避免反复电话确认。

**变更内容**:
- 报名表单在报名酒店下方新增选填的「备选酒店」下拉，选项排除当前报名酒店和暂停报名的酒店。
- `/api/apply` 新增可选入参 `backupHotel`，校验不通过直接拒绝。
- 飞书新增文本列「备选酒店」：填了备选时与报名信息同一次写入；列不存在先自动新增，已存在直接写；历史记录该列保持为空。
- 重复提交未填备选时清空该格。
- 备选列的检查或新增失败不影响报名本身，降级为不带备选写入并记录日志。
- 新增 AC-020 至 AC-024。
