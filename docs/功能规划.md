# 燚桐小程序功能规划

> 本文是后续产品拆分、开发排期和验收的功能基线。后续实现以本文为准；除非用户明确调整，否则不要再按旧 MVP 范围补功能。

## 0. 范围原则

- 用户端分为三大核心模块：表白墙、树洞、兼职。
- 用户端底部 tabBar 含「广场」tab（表白墙精简入口，左一位置），复用 PostVo 数据，关注 / 推荐 2 tab，无运营位。
- 表白墙按完整校园表白墙体验建设，不停留在发帖/点赞/评论 MVP。
- 树洞保留匿名身份、灵魂测试、匹配、1v1 聊天、群聊广场，不做礼物、打赏、虚拟币、付费装扮、直播打赏、短视频、视频聊天、实时语音通话、语音房、多人连麦、K 歌房。
- 树洞语音只做异步语音消息：录音、上传、播放、时长展示、保存聊天记录；不做语音消息举报。
- 兼职按青团社式找兼职、报名、简历、沟通、评价保障、商家招聘闭环建设。
- AI 相关能力全部不做，包括 AI 推荐、AI 破冰、AI 回复建议、AI 陪伴、AI 标签生成、AI 安全识别等。

## 1. 表白墙模块

### 1.1 内容流

目标：让用户打开表白墙后有可持续浏览的校园内容流，而不是只有单一列表。

功能清单：
- 推荐流
- 最新流
- 热门流
- 关注流
- 置顶最热帖子
- 滚动加载前十条
- 今日上头
- 今日上头对应滚动列表

落地说明：
- 推荐流初期可先用规则排序：置顶、加精、热度、时间衰减。
- 热门流按点赞、评论、收藏、分享、发布时间计算热度分。
- 关注流只展示已关注作者的内容。
- 今日上头作为运营位，展示当天热度最高或后台配置的内容集合。

### 1.2 发布能力

目标：支持用户完成正式表白、匿名表达、草稿沉淀和后续管理。

功能清单：
- 图文表白
- 匿名/实名发布
- 选择标签
- 图片发布
- 视频发布
- 表情发布
- 草稿箱
- 定时发布
- 发布后编辑
- 发布后删除
- 私密投稿
- 仅自己可见草稿

落地说明：
- 发布前必须走内容安全审核和关键词屏蔽。
- 匿名发布的展示身份与真实 uid 隔离；后台可按合规需要追溯。
- 草稿仅用户本人可见，不进入公开审核队列。
- 定时发布到点后进入审核或发布流程，不能绕过审核。

### 1.3 互动能力

目标：补齐社区互动闭环，让帖子有关系链、讨论和治理能力。

功能清单：
- 点赞
- 收藏
- 评论
- 评论回复
- 二级评论
- 评论点赞
- 分享到微信
- 举报
- 拉黑用户
- 关注作者
- 进入作者主页
- @用户
- 热评置顶

落地说明：
- 评论、回复、@ 提醒都要进入表白墙来源的消息通知。
- 拉黑后互相不可见或不可互动，具体规则开发前单独确认。
- 热评置顶可先由热度自动选取，后台再补人工置顶。

### 1.4 搜索与发现

目标：让用户能找帖子、找人、找话题。

功能清单：
- 搜索帖子内容
- 搜索用户昵称
- 搜索话题
- 历史搜索
- 热门搜索

落地说明：
- 搜索记录存用户维度，支持清空。
- 热门搜索可先按搜索次数统计，后续补后台运营配置。

### 1.5 我的表白墙

目标：入口放在“我的”页面下，进入后用 tab 列表承载个人相关内容。

功能清单：
- 我的发布
- 我的匿名发布管理
- 我的点赞
- 我的收藏
- 我的评论
- 关注/粉丝

落地说明：
- 匿名发布管理只能本人查看，不在公开主页展示真实身份。
- 我的评论要能跳回原帖和对应评论位置。

### 1.6 表白墙消息通知

目标：所有通知必须注明来源是“表白墙”，避免和树洞、兼职混淆。

功能清单：
- 点赞通知
- 评论通知
- 回复通知
- 关注通知
- 内容被下架通知
- 微信订阅消息关键提醒

落地说明：
- 站内消息保留完整记录。
- 微信订阅消息只做关键提醒，且必须由用户主动授权。

### 1.7 安全与运营

目标：保证社区内容可控、可审核、可运营。

功能清单：
- 内容安全审核
- 关键词屏蔽
- 举报处理
- 用户禁言/封禁
- 帖子置顶
- 帖子加精
- 帖子下架
- 活动专题
- 校园话题运营

落地说明：
- 发帖、评论、回复、图片、视频都必须纳入审核或风控。
- 后台需支持举报处理、封禁、禁言、下架、置顶、加精。

### 1.8 广场（表白墙精简入口）

定位：用户端首屏的轻量动态入口，与表白墙共用 PostVo 数据池，但只暴露「关注 / 推荐」2 个 tab，不放运营位。

页面要点：
- 顶部搜索（找人或搜话题复用表白墙搜索）+ 公告栏
- 主 tab：关注 / 推荐
- post-card 动态卡片流
- 悬浮发帖按钮

落地说明：
- 不做「最热」「今日上头」「活动专题」「校园话题」运营位（这些仍属于表白墙 P2-01/02/03/04 实现，前端不在任何页面直接暴露入口）。
- 启动 user 角色默认落广场；表白墙 tab 在左二位置提供 4 tab 完整浏览入口。
- 后端 0 改动，仅前端页面 + tabBar 配置调整。

## 2. 树洞模块

### 2.1 匿名身份体系

目标：建立树洞专用匿名身份，不暴露真实 uid。

功能清单：
- 匿名身份生成
- 匿名昵称
- 虚拟头像/Avatar
- 头像装扮
- 个性标签
- 兴趣标签
- 心情状态
- 匿名身份保护，不暴露真实 uid
- 黑名单/屏蔽

落地说明：
- anonToken、anonId、树洞内容表不得直接包含真实 uid。
- 头像装扮只做免费配置，不做付费装扮。
- 黑名单/屏蔽影响广场、匹配和聊天可见性。

### 2.2 灵魂测试与画像

目标：用问卷和标签支撑匹配，不接 AI。

功能清单：
- 性格测试
- 兴趣测试
- 三观问卷
- 心情问卷
- 标签画像
- 匹配度计算
- 相似灵魂推荐
- 每日匹配报告

落地说明：
- 匹配度用规则模型实现，例如标签重合、问卷答案相似度、心情状态匹配。
- 每日匹配报告基于规则统计生成，不接 AI 生成内容。

### 2.3 树洞广场

目标：提供匿名图文内容流和情绪分类浏览。

功能清单：
- 推荐广场
- 最新广场
- 情绪分类：开心、emo、吐槽、求安慰、学习、恋爱、迷茫
- 话题广场
- 图文瞬间
- 匿名评论
- 点赞
- 收藏
- 分享
- 举报
- 屏蔽

落地说明：
- 不做短视频瞬间。
- 推荐广场初期用规则排序，不做 AI 推荐。
- 匿名评论同样不得暴露真实 uid。

### 2.4 匹配玩法

目标：支持匹配后解锁聊天，形成树洞核心社交链路。

功能清单：
- 灵魂匹配
- 随机匹配
- 兴趣匹配
- 心情匹配
- 限时聊天
- 匹配后解锁聊天
- 匹配历史
- 重新匹配
- 不喜欢/跳过
- 匹配安全提示

落地说明：
- 不做实时语音匹配。
- 匹配算法初期用规则，不接 AI。
- 未匹配的匿名双方不能绕过接口直接聊天。

### 2.5 1v1 聊天

目标：匹配后支持文字、图片、语音消息聊天。

功能清单：
- 文字消息
- 图片消息
- 语音消息
- 表情
- 撤回
- 已读/未读
- 拉黑
- 举报
- 聊天记录
- 断线重连
- 在线状态
- 破冰问题
- 聊天安全审核

语音消息范围：
- 录音发送
- 语音上传
- 语音播放
- 语音时长展示
- 语音消息保存到聊天记录

明确不做：
- 语音消息举报
- 实时语音通话
- 视频聊天
- AI 回复建议

### 2.6 群聊广场与群聊

目标：支持用户发现、创建、加入文字群聊。

功能清单：
- 群聊广场
- 推荐群聊
- 最新群聊
- 热门群聊
- 群聊分类：学习、情绪陪伴、游戏、恋爱、吐槽、同校
- 创建群聊
- 群聊名称
- 群聊头像
- 群聊简介
- 群聊标签
- 群聊人数上限
- 群聊公开/私密
- 群聊加入申请，可选
- 加入群聊
- 退出群聊
- 群成员列表
- 群主
- 管理员
- 群公告
- 文字群聊消息
- 图片消息
- 表情
- 消息撤回
- 群成员禁言
- 群成员踢出
- 群聊举报
- 群聊搜索
- 群聊详情页
- 我的群聊列表

明确不做：
- 语音房
- 多人连麦
- K 歌房
- 视频群聊

## 3. 兼职模块

### 3.1 找兼职首页

目标：提供接近青团社的岗位发现入口。

功能清单：
- 推荐岗位
- 附近岗位
- 最新岗位
- 热门岗位
- 精品兼职
- 急招岗位

落地说明：
- 附近岗位需要岗位地点结构化，初期可先按工作地点文本筛选，后续再接地图坐标。
- 推荐岗位初期按规则，不接 AI。

### 3.2 岗位分类

功能清单：
- 餐饮
- 零售
- 促销
- 展会
- 家教
- 校园代理
- 线上兼职
- 问卷/调研
- 实习
- 长期兼职
- 日结
- 周结
- 月结

落地说明：
- 分类需要成为岗位结构化字段，不只做前端静态筛选。

### 3.3 筛选搜索

功能清单：
- 关键词搜索
- 工作地点
- 薪资范围
- 结算方式
- 工作日期
- 工作时段
- 性别要求
- 是否包餐
- 是否有培训
- 是否急招
- 是否可线上

落地说明：
- 筛选字段要进入岗位模型和后台发布表单。
- 性别要求等敏感字段上线前需确认合规展示方式。

### 3.4 岗位详情

功能清单：
- 岗位标题
- 薪资
- 地点
- 工作时间
- 招聘人数
- 结算方式
- 工作内容
- 任职要求
- 商家信息
- 风险提示
- 联系商家
- 收藏
- 分享
- 举报

落地说明：
- 风险提示作为固定区块展示。
- 联系商家优先走站内聊天，电话联系需做号码保护或授权展示。

### 3.5 报名流程

功能清单：
- 极速报名
- 简历报名
- 报名问题
- 报名成功通知
- 报名状态跟踪
- 取消报名
- 重复报名拦截
- 录用通知
- 未录用通知

落地说明：
- 报名状态至少包含：待处理、已录用、未录用、已取消。
- 微信订阅消息只用于关键状态通知。

### 3.6 简历体系

功能清单：
- 基础简历
- 联系方式
- 空闲时间
- 工作经历
- 技能标签
- 自我介绍
- 实习简历
- 简历完整度
- 简历投递记录

落地说明：
- 简历可以先做一份通用简历，后续再扩展实习简历。
- 简历投递记录关联报名记录。

### 3.7 沟通与通知

功能清单：
- 在线聊天
- 电话联系保护
- 报名状态通知
- 录用通知
- 微信订阅消息
- 消息中心

落地说明：
- 在线聊天复用现有聊天基础设施。
- 电话联系保护初期可先做“点击后授权展示”，后续再做虚拟号。

### 3.8 评价与保障

功能清单：
- 学生评价商家
- 商家评价学生
- 岗位评分
- 商家评分
- 黑名单商家
- 投诉举报
- 平台审核
- 薪资保障说明
- 客服工单

落地说明：
- 投诉举报和客服工单需要后台处理入口。
- 薪资保障说明先做规则说明页，后续再接真实赔付或仲裁流程。

### 3.9 商家端招聘闭环

功能清单：
- 商家入驻
- 营业执照/身份认证
- 商家资料
- 发布岗位
- 岗位付费/推广
- 岗位审核
- 报名管理
- 批量录用/拒绝
- 在线沟通
- 发票/账单
- 招聘数据看板

落地说明：
- 商家发布岗位必须经过审核和支付/推广规则。
- 批量录用/拒绝要保留操作记录。
- 发票/账单先做订单与账单记录，真实开票能力后续单独评估。

## 4. 分期建议

### P0：补齐主链路

- 表白墙：推荐/最新/热门/关注流、发布增强、评论回复、举报、关注、我的表白墙、来源化消息。
- 树洞：匿名身份、图文广场、规则匹配、匹配后 1v1 文字/图片聊天、聊天安全审核、黑名单。
- 兼职：岗位结构化字段、分类筛选、岗位详情、极速报名、简历报名、报名状态、商家报名管理。

### P1：补齐社区互动和管理能力

- 表白墙：二级评论、评论点赞、@用户、热评置顶、搜索、历史搜索、热门搜索、禁言/封禁、置顶/加精/下架。
- 树洞：兴趣/心情标签、灵魂测试、匹配度、匹配历史、重新匹配、跳过、语音消息。
- 兼职：简历完整度、投递记录、取消报名、未录用通知、商家评价学生、学生评价商家、投诉举报。

### P2：补齐广场、群聊和运营能力

- 表白墙：今日上头、活动专题、校园话题运营、定时发布、私密投稿。
- 树洞：群聊广场、创建群聊、群聊详情、群成员管理、群公告、群聊搜索、我的群聊。
- 兼职：精品/急招岗位、招聘数据看板、发票/账单、电话联系保护、薪资保障说明、客服工单。

## 5. 验收原则

- 每个功能必须有用户入口、后端数据模型/API、权限校验、异常处理和消息/审核策略。
- 匿名相关功能必须证明不泄露真实 uid。
- 支付金额必须服务端计算。
- 内容发布、评论、聊天、举报相关功能必须考虑内容安全和后台处理。
- 微信订阅消息只能作为关键提醒，不替代站内消息。
- 不做项不得以“占位功能”形式偷偷接入。
