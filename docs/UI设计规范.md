# 燚桐 UI 设计规范

> 本文是燚桐用户端、商家端、管理端的统一视觉与交互基线。后续页面重构和新功能开发必须优先遵守本文，避免把表白墙、树洞、兼职做成三个割裂产品。

## 1. 设计定位

燚桐是一个统一的校园生活平台，不是表白墙、树洞、兼职三个平台的拼接。

设计关键词：
- 成熟
- 干净
- 可信
- 年轻
- 信息清晰
- 有校园生活感但不幼稚

不做：
- 三个频道三套颜色
- 大面积渐变
- 卡通低龄风
- 过度粉色社交感
- 过度蓝色招聘工具感
- 装饰性大于信息表达的界面

## 2. 色彩系统

### 2.1 品牌主色

- 品牌黄：`#F9C801`

使用原则：
- 品牌黄是全平台唯一主色，表白墙、树洞、兼职不再设置频道专属主色。
- 品牌黄适合做选中态、关键按钮背景、重点数字、徽标、轻提示。
- 不允许大面积整屏铺黄色。
- 不允许黄底承载白色小字；黄底文字优先使用深色文字。

### 2.2 主色衍生

- 深黄：`#C59A00`
- 浅黄底：`#FFF7D1`
- 极浅黄底：`#FFFBEA`

使用原则：
- 深黄用于按下态、描边强调、少量关键数字。
- 浅黄底用于选中标签、轻提示、重点信息背景。
- 极浅黄底仅用于局部信息提示，不做页面背景主色。

### 2.3 中性色

- 页面背景：`#F6F7FB`
- 卡片背景：`#FFFFFF`
- 主文字：`#1D2129`
- 正文文字：`#4E5969`
- 次文字：`#86909C`
- 弱文字：`#C9CDD4`
- 边框/分割线：`#E5E6EB`
- 遮罩：`rgba(0, 0, 0, 0.45)`

### 2.4 状态色

- 成功：`#00B42A`
- 信息：`#2F80ED`
- 警示：`#FFB020`
- 危险：`#F53F3F`
- 禁用背景：`#F2F3F5`
- 禁用文字：`#C9CDD4`

状态色只用于状态表达，不作为频道色使用。

## 3. 字体与层级

小程序端使用系统字体，不引入额外字体包。

字号建议：
- 页面标题：36rpx，字重 600
- 区块标题：32rpx，字重 600
- 卡片标题：30rpx，字重 600
- 正文：28rpx，字重 400
- 辅助信息：24rpx，字重 400
- 标签/角标：22rpx，字重 500
- 价格/关键数字：36rpx 或 40rpx，字重 700

原则：
- 不用超大标题制造“营销页感”。
- 列表页优先保证可扫描性。
- 关键数字可以更醒目，但不能挤压正文信息。

## 4. 间距与圆角

基础间距：
- 页面左右边距：24rpx
- 卡片内边距：24rpx
- 卡片间距：20rpx
- 区块上下间距：32rpx
- 列表项内部小间距：8rpx / 12rpx / 16rpx

圆角：
- 卡片：16rpx
- 按钮：12rpx 或胶囊按钮
- 标签：999rpx 胶囊
- 输入框：12rpx
- 弹窗：20rpx

原则：
- 不使用夸张大圆角。
- 不把多个大卡片套在大卡片里。
- 同一页面内卡片圆角必须一致。

## 5. 页面结构

用户端主频道统一结构：
1. 顶部标题/搜索/主要操作
2. 频道核心入口或运营位
3. tab 或筛选区
4. 内容列表
5. 空状态/加载状态/错误状态

表白墙、树洞、兼职的差异只体现在内容组织，不体现在颜色体系。

商家端主页面统一结构：
1. 工作台概览
2. 待处理事项
3. 核心操作入口
4. 数据/状态列表

管理端主页面统一结构：
1. 筛选区
2. 状态统计
3. 表格/审核队列
4. 批量操作

## 6. 组件规范

### 6.1 按钮

主按钮：
- 背景：`#F9C801`
- 文字：`#1D2129`
- 高度：88rpx
- 圆角：12rpx 或胶囊
- 用于发布、报名、确认、保存、提交等主操作。

次按钮：
- 背景：`#FFFFFF` 或 `#F2F3F5`
- 文字：`#1D2129`
- 边框：`#E5E6EB`
- 用于取消、筛选、次级操作。

危险按钮：
- 背景或文字使用 `#F53F3F`
- 用于删除、举报、下架、封禁等。

按钮原则：
- 一个操作区只保留一个主按钮。
- 列表卡片内小操作优先使用小按钮或图标按钮。
- 禁用态必须降低对比，不允许只靠文案表达。

### 6.2 卡片

基础卡片：
- 背景：`#FFFFFF`
- 圆角：16rpx
- 内边距：24rpx
- 边框：`1rpx solid #E5E6EB`
- 阴影：默认不用；重要浮层可用极轻阴影。

卡片原则：
- 信息顺序固定：标题/主体信息/标签/辅助信息/操作。
- 不在卡片里再套装饰卡片。
- 卡片不大面积使用品牌黄。

### 6.3 标签

普通标签：
- 背景：`#F2F3F5`
- 文字：`#4E5969`

重点标签：
- 背景：`#FFF7D1`
- 文字：`#1D2129`

状态标签：
- 待审核/待处理：警示色浅底
- 已通过/已录用/已完成：成功色浅底
- 已拒绝/已下架/失败：危险色浅底
- 已发布/进行中：信息色浅底

原则：
- 标签文字尽量 2-6 个字。
- 不使用高饱和大色块堆满卡片。

### 6.4 输入与表单

输入框：
- 背景：`#FFFFFF`
- 边框：`#E5E6EB`
- 聚焦边框：`#F9C801`
- 错误边框：`#F53F3F`

表单原则：
- 发布、报名、简历、商家入驻等长表单必须分区。
- 必填项清晰标注。
- 错误提示贴近字段，不只用 toast。
- 底部固定提交按钮。

### 6.5 tab 与筛选

tab：
- 选中文字：`#1D2129`
- 选中下划线：`#F9C801`
- 未选中：`#86909C`

筛选：
- 筛选项使用浅灰底或白底描边。
- 已选筛选项使用浅黄底。

### 6.6 空状态

空状态包含：
- 统一线性图标或轻插画
- 一句明确原因
- 一个可选主操作

原则：
- 不用夸张卡通图。
- 文案直接说明下一步，不写空泛鼓励语。

## 7. 图标规范

- 小程序端优先使用统一线性图标风格。
- 图标线宽一致，默认深灰，选中态用品牌黄或主文字色。
- 不混用多套风格：线性、实心、卡通图标不能混杂。
- 常见操作优先用图标：点赞、评论、收藏、分享、搜索、筛选、返回、更多、举报。

## 8. 三端统一规则

### 8.1 用户端

用户端更强调内容浏览和轻互动，但仍遵守统一平台视觉。

重点：
- 信息流卡片统一
- 底部 tabBar 统一
- 搜索、发布、筛选入口统一
- 表白墙、树洞、兼职不使用独立频道色

### 8.2 商家端

商家端是平台里的招聘工作台，不是独立后台。

重点：
- 信息密度高于用户端
- 待处理事项优先
- 数据卡片清晰
- 主操作用品牌黄
- 状态标签统一

### 8.3 管理端

管理端更克制，服务审核和运营。

重点：
- 表格、筛选、批量操作为主
- 避免大面积品牌色
- 只在主操作、选中态、重点统计中使用品牌黄
- 审核、举报、封禁、订单状态全部使用统一状态色

## 9. 频道页面方向

### 9.0 广场（圈子 Community 首页）

定位：用户端首屏的**圈子（Community）首页**。圈子是用户可加入/创建/切换的社区；圈子动态仅聚合表白墙和树洞，兼职保留独立 tab，不混入动态流。普通内容按圈子隔离，“燚桐家教”同步岗位仅在独立兼职列表中作为窄范围例外跨圈展示。与表白墙/树洞/兼职各自独立入口并存。

页面要点（按目标 UI，圈红区域不做）：
- 顶部搜索栏**左侧圈子切换按钮**（当前圈 LOGO/首字占位，点开圈子切换页）+ 搜索栏（进入内容搜索）+ 公告栏
- **圈子头卡**：LOGO（无则名称首字占位）+ 名称 + 「动态 N · 成员 M」；点击进圈子列表/切换页
- **广告位轮播**：Banner 横向 swiper（indicator-dots，autoplay circular）；圈子 Banner + 全局 Banner，sortOrder asc
- **今日上头**：⚡ 标题 + 横向 scroll-view Top10 迷你卡（序号 + 类型徽标[表白墙/树洞] + 内容摘要 + 👀浏览量）；点击跳对应详情
- **4 tab**：圈子动态 / 表白墙 / 树洞 / 兼职（选中下划线 `#F9C801`，未选中 `#86909C`）
  - 圈子动态 = 两源混合流（post-card / 匿名降级卡），**曝光度 = 付费推广前置**，其余按时间；不展示兼职岗位
  - 表白墙 / 树洞 tab = 圈子作用域列表（付费推广前置）；兼职 tab = 当前圈普通岗位 + 全圈“燚桐家教”同步岗位（job-card）
- 匿名帖卡片降级：去真实头像/昵称，顶部「匿名」灰色标签 + 匿名昵称 + mood
- 悬浮发帖按钮（发帖归属当前圈子）

圈子交互页面 UI 要点（对照目标 UI）：
- **加入圈子页**：顶部「创建圈子」主按钮 + 圈子卡片列表（LOGO/首字占位 + 名称 + 成员数）；点卡片加入并置为当前，`switchTab` 回广场
- **创建圈子页**：LOGO + 名称 + **类型 chips**（校园/兴趣/生活/兼职，必选，选中浅黄底）+ **所在地区** + **所在地点** + 简介 + 底部固定提交按钮
- **圈子切换页**：当前圈子头卡（大 LOGO + 名称 + 动态/成员数）+ 右上角「···」→ `showActionSheet` 底部菜单「退出圈子」；「我的圈子」列表 + 圈子广场 / 搜索圈子 / 创建圈子入口
- **圈子广场页**：左侧类型列表（全部 + 校园/兴趣/生活/兼职，选中浅黄底）+ 右侧该类型圈子列表；成员圈子点卡切换并回广场；非成员卡片内「加入」按钮
- **圈子搜索页**：搜索栏 + 历史搜索 chips + 结果列表（成员→切换回广场，非成员→加入回广场）
- **内容搜索页**：3 tab 表白墙 / 树洞 / 兼职（选中下划线 `#F9C801`）+ 历史搜索 chips + 结果列表
- **我的圈子页 (CR-004)**：3 tab 「已加入 / 待审核 / 未通过」（选中下划线 `#F9C801`）
  - 已加入：复用空白态 + 主按钮「创建圈子」+ 次按钮「去圈子广场逛逛」；卡片沿用 §3 卡片规格
  - 待审核：每行右侧徽标「审核中」（警示色浅底 #FFB020 / 底色 rgba(255,176,32,0.15)）；底部一行提示「管理员正在审核中，通过后会通知你」
  - 未通过：danger 边框卡片（边框 `#F53F3F` / 浅底拒绝原因块 `#FFEDED`）+ 底部固定主按钮「重新提交」（高 88rpx / 圆角 12rpx / 主色 `#F9C801`）；提交中文字切「提交中…」+ disabled
- **创建圈子页 toast (CR-004)**：按 create 接口返回的 `pending` 字段切文案——`pending=true` 弹「已提交，等待审核」后 `reLaunch` 跳 `pages/community/mine?tab=pending`；`pending=false` 维持「创建成功」跳广场
- 以上页面沿用统一平台视觉：卡片 16rpx 圆角、品牌黄选中态、浅黄底选中标签，不给圈子单独配色

匿名卡样式要点（沿用 CR-001）：
- **头像位置**：匿名 emoji 占位，不复用真实头像
- **昵称**：匿名昵称（如「温柔的星星」），不使用真实昵称
- **「匿名」标识**：昵称右侧灰色小标签「匿名」
- **mood**：显示树洞 mood 标签
- **点赞 / 评论按钮**：anonToken 缺失时 disabled（透明度 0.5）+ toast「请前往树洞签发匿名身份后互动」
- **卡片整体**：复用 post-card 骨架，替换头像区 / 昵称区 / 「匿名」标识

明确不做：
- 群聊广场 / 群聊帖 / 匹配 / 聊天入口（属树洞模块，不在广场暴露）
- 圈子成员角色管理（踢/禁/转让）/ 圈子编辑 / 圈子删除（后续方向）

广场在 tabBar 左一位置，user 角色启动默认落广场。表白墙 tab 仍在左二位置提供 4 tab 完整浏览入口；树洞 tab 保留匿名身份与匹配入口；兼职 tab 保留岗位发现入口（全局视图）。

### 9.1 表白墙

定位：校园动态频道。

页面要点：
- 顶部搜索 + 发布入口
- 推荐/最新/热门/关注 tab
- 动态卡片流
- 帖子详情底部固定评论输入

表白墙不使用粉色作为频道主色。

### 9.2 树洞

定位：匿名情绪频道。

页面要点：
- 匿名身份卡
- 心情状态入口
- 匹配入口
- 群聊广场入口
- 推荐/最新/情绪分类 tab
- 匹配后进入聊天

树洞不使用紫色作为频道主色。

### 9.3 兼职

定位：校园兼职服务频道。

页面要点：
- 顶部搜索 + 筛选
- 推荐/附近/最新/急招 tab
- 分类入口
- 岗位卡片突出薪资、地点、时间、结算方式
- 详情页底部固定报名按钮

兼职不使用蓝色作为频道主色。

## 10. 明确禁止

- 不做三个频道三套视觉。
- 不用大面积黄色铺底。
- 不用黄底白字小按钮。
- 不用大面积渐变背景。
- 不做卡片套卡片。
- 不做营销落地页式 hero。
- 不在功能页面堆解释性文案。
- 不用 AI、礼物、打赏、视频、实时语音房等已明确排除的功能做视觉占位。

## 11. 首批重构目标

首批 UI 重构先做统一平台感：
1. 全局颜色变量、按钮、标签、卡片、页面背景
2. tabBar 选中态与图标统一
3. 表白墙首页
4. 树洞首页
5. 兼职首页
6. 我的页
7. 岗位详情页
8. 树洞匹配页
9. 聊天页

验收标准：
- 一眼看起来是一个平台。
- 三个频道没有独立配色割裂感。
- 页面不像 MVP Demo。
- 列表、卡片、按钮、标签、状态在不同页面一致。
- 品牌黄 `#F9C801` 使用克制，重点明确，可读性良好。
