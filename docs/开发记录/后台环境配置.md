## 1. Docker 安装与镜像加速

### 1.1 安装 Docker Desktop

从 [docker.com](https://www.docker.com/products/docker-desktop/) 下载并安装 Docker Desktop for Windows，启用 WSL2 后端。

### 1.2 配置国内镜像加速源

由于 Docker Hub 在国内访问缓慢/超时，需配置镜像加速。

**方式一：修改 daemon.json（推荐）**

编辑 `%USERPROFILE%\.docker\daemon.json`：

```json
{
  "builder": {
    "gc": {
      "defaultKeepStorage": "20GB",
      "enabled": true
    }
  },
  "experimental": false,
  "registry-mirrors": [
    "https://docker.1ms.run",
    "https://docker.1panel.live",
    "https://hub.rat.dev"
  ]
}
```

修改后重启 Docker Desktop。

**方式二：直接通过镜像源拉取并重新打 tag**

当 Docker Desktop GUI 未生效时，可绕过直接拉取：

```powershell
# 通过镜像源拉取
docker pull docker.1ms.run/library/postgres:16-alpine
docker pull docker.1ms.run/library/redis:7-alpine

# 重新 tag
docker tag docker.1ms.run/library/postgres:16-alpine postgres:16-alpine
docker tag docker.1ms.run/library/redis:7-alpine redis:7-alpine
```

## 2. Docker Compose 服务编排

项目根目录 `docker-compose.yml`：

```yaml
services:
  postgres:
    image: postgres:16-alpine
    container_name: yitong-postgres
    restart: always
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: yitong
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    networks:
      - yitong-network

  redis:
    image: redis:7-alpine
    container_name: yitong-redis
    restart: always
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    networks:
      - yitong-network

volumes:
  postgres_data:
  redis_data:

networks:
  yitong-network:
    driver: bridge
```

### 服务端口映射

| 服务 | 容器端口 | 宿主机端口 | 说明 |
|---|---|---|---|
| PostgreSQL | 5432 | 5432 | 数据库 |
| Redis | 6379 | 6379 | 缓存/Session |

### 数据库连接信息

```
Host:     localhost
Port:     5432
User:     postgres
Password: postgres
Database: yitong
URL:      postgresql://postgres:postgres@localhost:5432/yitong
```

该连接串已配置在 `apps/server/.env` 的 `DATABASE_URL` 中。

## 3. 容器管理命令

```powershell
# 启动所有服务
docker compose up -d

# 停止所有服务（保留数据卷）
docker compose down

# 停止并删除数据卷（⚠️ 清空所有数据）
docker compose down -v

# 查看运行状态
docker ps

# 查看日志
docker compose logs -f postgres
docker compose logs -f redis

# 进入 PostgreSQL 命令行
docker exec -it yitong-postgres psql -U postgres -d yitong

# 进入 Redis 命令行
docker exec -it yitong-redis redis-cli
```

## 4. Prisma 数据库迁移

### 4.1 首次初始化

```powershell
cd apps/server

# 生成 Prisma Client
pnpm prisma:generate

# 运行迁移（创建所有表）
pnpm prisma migrate dev --name init
```

### 4.2 Schema 变更后迁移

```powershell
# 修改 prisma/schema.prisma 后
pnpm prisma migrate dev --name <描述>

# 或直接推送（开发环境，跳过迁移文件）
pnpm prisma db push
```

### 4.3 Prisma Studio（可视化管理）

```powershell
cd apps/server
pnpm prisma studio
# 自动打开浏览器 http://localhost:5555
```

### 4.4 首次迁移结果

- **迁移名称**：`20260705071638_init`
- **状态**：已成功应用
- **Prisma Client**：已重新生成

## 6. 常见问题

### Q: 容器启动后 PostgreSQL 拒绝连接？

容器刚启动时 PostgreSQL 可能还在初始化中，等待 3-5 秒再重试。

### Q: Prisma migrate 报连接错误？

确认 Docker 容器是否在运行：
```powershell
docker ps | findstr yitong
```

### Q: 镜像拉取超时 / EOF？

Docker Hub 被墙，通过 `docker.1ms.run` 等镜像源中转拉取（见 1.2 节）。

### Q: 如何完全重置数据库？

```powershell
# 停止并删除容器 + 数据卷
docker compose down -v

# 重新启动
docker compose up -d

# 重新迁移
cd apps/server && pnpm prisma migrate dev --name init
```

### Q: 端口 5432 或 6379 被占用？

修改 `docker-compose.yml` 中的端口映射，如 `"5433:5432"`，同时更新 `.env` 中的 `DATABASE_URL` 端口号。
