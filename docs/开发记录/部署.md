# 燚桐部署指南

> 生产部署：已有 Linux 服务器 + 单机 Docker Compose（postgres + redis + minio + server + nginx 一体）。
> 聊天为自建 WebSocket（:3001，经 nginx /ws 反代为 wss），无腾讯云 IM / MobileIMSDK 容器。
> 对象存储生产沿用 MinIO 容器（与 dev 一致，零代码改动），公网经 nginx /files 代理访问。

## 前置条件
- Linux 服务器（Ubuntu/Debian/CentOS），内存 ≥2G（建议 4G：PG+Redis+MinIO+Node+Nginx 同机）
- Docker Engine + Compose v2
- 域名已解析到服务器公网 IP + **ICP 备案通过**（微信小程序硬性要求）
- TLS 证书（443 + wss；云厂商免费 DV 或 Let's Encrypt）
- 安全组只放行 22/80/443；**禁止放行 3000/3001/5432/6379/9000**

> ⚠️ 服务器上只用 `docker-compose.prod.yml`（内部端口不对外）。dev 的 `docker-compose.yml` 把 5432/6379/9000 映射到宿主机，**切勿在服务器使用**。

## 方式一：Docker Compose（推荐，生产）

### 1. 装 Docker（若未装）
```bash
curl -fsSL https://get.docker.com | sh
```

### 2. 拉代码
```bash
git clone https://github.com/Alenchenxi/yitong.git
cd yitong
```

### 3. 配生产环境变量
```bash
cp .env.production.example .env.production
# 编辑 .env.production：DOMAIN / DB_PASSWORD / JWT_SECRET / ADMIN_API_KEY / ADMIN_OPENID /
#   WX_USER_SECRET / WX_PAY_* / WX_SUBSCRIBE_* / MINIO_ACCESS_KEY / MINIO_SECRET_KEY / MINIO_PUBLIC_URL
```
🔴 必查：
- `MODE=prod`（dev 会跳过角色权限校验=后台裸奔）
- `JWT_SECRET` / `ADMIN_API_KEY` / `DB_PASSWORD` / `MINIO_ACCESS_KEY` / `MINIO_SECRET_KEY` 全换强随机
- `MINIO_PUBLIC_URL=https://<域名>/files`
- `WX_PAY_NOTIFY_URL` / `WX_PAY_REFUND_NOTIFY_URL` 用 https 域名

### 4. 放 TLS 证书
```bash
mkdir -p certs
# 把 fullchain.pem 和 privkey.pem 放到 ./certs/（云厂商免费 DV 证书下载后重命名）
```
（用 certbot 签发见文末「TLS 证书」一节。）

### 5. 启动全栈
```bash
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --build
```

### 6. 跑迁移 + 种子
```bash
docker exec yitong-server node /app/node_modules/.bin/prisma migrate deploy \
  --schema /app/apps/server/prisma/schema.prisma
docker exec yitong-server node /app/node_modules/.bin/prisma db seed \
  --schema /app/apps/server/prisma/schema.prisma
```

### 7. 微信小程序后台配服务器域名
- request 合法域名：`https://<域名>`
- socket 合法域名：`wss://<域名>`
- uploadFile / downloadFile 合法域名：`https://<域名>`

### 8. 验证
```bash
curl https://<域名>/health        # -> ok
curl https://<域名>/api/v1/...    # 接口通
```
小程序全链路：登录 -> 发帖上传图 -> 树洞 -> 兼职报名 -> 支付回调。

服务清单（生产）：
- nginx :80/:443（反代 API + WS + 文件）
- server :3000（HTTP，仅容器内网）+ :3001（WS，仅容器内网）
- postgres :5432 / redis :6379 / minio :9000（均仅容器内网，minio 经 nginx /files 对外）

## 方式二：PM2（不用 Docker 全栈时）

```bash
# 1. 起 PostgreSQL + Redis + MinIO（本机或仅 dev compose）
docker compose up -d  # 仅 postgres + redis + minio

# 2. 安装依赖 + 构建
pnpm install
pnpm --filter @yitong/shared-types build
pnpm --filter @yitong/shared-utils build
pnpm --filter @yitong/server prisma generate
pnpm --filter @yitong/server prisma migrate deploy
pnpm --filter @yitong/server prisma db seed
pnpm --filter @yitong/server build

# 3. PM2 启动
pm2 start ecosystem.config.js --env production
pm2 save
pm2 startup  # 开机自启
```

## 环境变量（.env.production）

| 变量 | 说明 | 示例 |
|-|-|-|
| `MODE` | 🔴 生产必须 `prod` | `prod` |
| `DOMAIN` | 域名（compose 拼接 CHAT_WS_URL 用） | `yourdomain.com` |
| `DB_PASSWORD` | 数据库密码（compose 拼接 DATABASE_URL） | 强随机 |
| `DATABASE_URL` | 由 compose 注入，无需手填 | `postgresql://postgres:***@postgres:5432/yitong` |
| `REDIS_URL` | 由 compose 注入 | `redis://redis:6379` |
| `JWT_SECRET` | JWT 签名密钥 | 随机长字符串 |
| `CHAT_WS_URL` | 由 compose 注入（`wss://${DOMAIN}/ws`） | `wss://yourdomain.com/ws` |
| `WX_USER_APPID` | 微信小程序 AppID | `wx6d60329e0114a09a` |
| `WX_USER_SECRET` | 微信小程序 Secret | 从公众平台获取 |
| `MINIO_*` | MinIO 凭证 + 公网 URL | `MINIO_PUBLIC_URL=https://域名/files` |
| `ADMIN_OPENID` | 管理员微信 openid | 配真实 openid 后管理员可登录 |
| `WX_PAY_*` | 微信支付商户凭证 | 付费发布用 |
| `TUTOR_SYNC_ENABLED` | 家教同步总开关；生产启用填 `true` | `false` |
| `TUTOR_SYNC_URL` | 家教平台完整快照接口地址 | `https://tutor.example/api/internal/sync/tutor-demands` |
| `TUTOR_SYNC_TOKEN` | 两端一致的共享令牌，仅放部署环境 | 强随机 |

家教同步的“单次快照上限”不使用环境变量。管理员在小程序管理端进入“运营 -> 设置 -> 系统同步配置”维护，存储键为 `app_configs.tutor_sync.max_demands`；默认 100 条，允许 1-200 条。Token、URL 等部署秘密不会通过管理 API 返回。

## Nginx 配置

`nginx.conf` 已含：
- 80：certbot 验证 + 健康探活 + 跳 443
- 443：TLS + `/api/` -> server:3000 + `/ws` -> server:3001(wss) + `/files/` -> minio:9000
- `client_max_body_size 50m`（视频上传上限 50MB）

证书路径 `./certs/fullchain.pem` + `./certs/privkey.pem`（挂载到 `/etc/nginx/certs/`）。

## TLS 证书

**方式 A：云厂商免费 DV 证书（推荐，最省事）**
腾讯云/阿里云 SSL 控制台申请免费 1 年 DV 证书，下载 Nginx 版，把证书文件重命名为 `fullchain.pem`、私钥为 `privkey.pem` 放入 `./certs/`。

**方式 B：Let's Encrypt（certbot）**
```bash
# 先装 certbot；临时让 nginx 仅跑 80（注释 nginx.conf 的 443 块后 nginx -s reload）
mkdir -p certbot-www certs
docker run --rm \
  -v "$(pwd)/certbot-www:/var/www/certbot" \
  -v "$(pwd)/certs:/etc/letsencrypt" \
  certbot/certbot certonly --webroot -w /var/www/certbot \
  -d <域名> --email <你的邮箱> --agree-tos --no-eff-email
# 签发后链接到 ./certs/fullchain.pem / privkey.pem，放开 nginx 443 块重启
# fullchain: certs/live/<域名>/fullchain.pem ; privkey: certs/live/<域名>/privkey.pem
```

## 定时任务

岗位到期下架 cron 内置 server（`@Cron('0 * * * *')` 每小时），无需额外配置。
dev 手动触发：`POST /api/v1/job-posts/expire-now`（需登录，prod 禁止）。

家教完整快照同步 cron 同样内置 server，每 5 分钟执行。启用前必须应用 Prisma migration，并配置 `TUTOR_SYNC_ENABLED=true`、`TUTOR_SYNC_URL`、`TUTOR_SYNC_TOKEN`。同步不调用微信内容审核；源数据经字段与生命周期校验后直接适配。上线前在隔离 PostgreSQL 对 nearest 查询执行 `EXPLAIN (ANALYZE, BUFFERS)`，核对经纬度部分索引、advisory lock 和事务回滚。

## 数据备份

单机自建 PG/Redis/MinIO 数据全在 docker named volume，需自备备份：
```bash
# PG 备份
docker exec yitong-postgres pg_dump -U postgres yitong > backup_$(date +%F).sql
# MinIO 数据在 minio_data 卷；Redis 在 redis_data 卷
```
建议加 cron 定时异地备份（对象存储/另一台机器）。

## 常见问题

- **GitHub push 超时**：本机到 GitHub 网络不稳，多重试或走代理。
- **Docker Desktop 未运行**（本机 dev）：`"/c/Program Files/Docker/Docker/Docker Desktop.exe"` 启动。
- **prisma migrate 非交互**：用 `migrate deploy`（生产）+ `migrate diff --script`（见改动记录）。
- **nginx 启动失败**：检查 `./certs/fullchain.pem` + `privkey.pem` 是否存在；证书路径不对报 `cannot load certificate`。
- **微信支付回调收不到**：确认 `WX_PAY_NOTIFY_URL` 是公网 https、安全组放行 443、域名备案通过。
