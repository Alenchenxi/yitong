# 燚桐部署指南

## 前置条件
- Docker + Docker Compose（推荐）
- 或 Node 20+ / pnpm / PM2（不用 Docker 时）
- 域名 + ICP 备案（微信小程序要求）+ TLS 证书（wss）

## 方式一：Docker Compose（推荐）

```bash
# 1. 配置环境变量（复制 .env.example 改值）
cp .env.example .env.production
# 编辑 .env.production：JWT_SECRET / DB_PASSWORD / DOMAIN / ADMIN_OPENID / WX_* / COS_* 等

# 2. 启动全栈
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --build

# 3. 跑迁移 + 种子
docker exec yitong-server node node_modules/.bin/prisma migrate deploy
docker exec yitong-server node node_modules/.bin/prisma db seed
```

服务：
- nginx :80（反代 API + WS）
- server :3000（NestJS HTTP）+ :3001（WebSocket 聊天）
- postgres :5432
- redis :6379

## 方式二：PM2（不用 Docker）

```bash
# 1. 起 PostgreSQL + Redis（本机或 Docker）
docker compose up -d  # 仅 postgres + redis

# 2. 安装依赖 + 构建
pnpm install
pnpm --filter @yitong/shared-types build
pnpm --filter @yitong/shared-utils build
pnpm --filter @yitong/server prisma generate
pnpm --filter @yitong/server prisma migrate deploy
pnpm --filter @yitong/server prisma db seed
pnpm --filter @yitong/server build

# 3. PM2 启动
pm2 start ecosystem.config.js --env production
pm2 save
pm2 startup  # 开机自启
```

## 环境变量（.env.production）

| 变量 | 说明 | 示例 |
|-|-|-|
| `DATABASE_URL` | PostgreSQL 连接 | `postgresql://postgres:pass@localhost:5432/yitong` |
| `REDIS_URL` | Redis 连接 | `redis://localhost:6379` |
| `JWT_SECRET` | JWT 签名密钥 | 随机长字符串 |
| `CHAT_WS_URL` | WebSocket 地址（给客户端） | `wss://yourdomain.com/ws` |
| `CHAT_WS_PORT` | WS 服务端监听端口 | `3001` |
| `WX_USER_APPID` | 微信小程序 AppID | `wx6d60329e0114a09a` |
| `WX_USER_SECRET` | 微信小程序 Secret | 从公众平台获取 |
| `COS_*` | 腾讯云 COS 凭证 | |
| `ADMIN_OPENID` | 管理员微信 openid | 配真实 openid 后管理员可登录 |
| `WX_PAY_*` | 微信支付商户凭证 | 付费发布用 |

## Nginx 配置

`nginx.conf` 已含：
- `/api/` -> server:3000（HTTP 反代）
- `/ws` -> server:3001（WebSocket upgrade）
- 生产需加 TLS（443 + wss），用 certbot 或手动证书

## 定时任务

岗位到期下架 cron 内置于 server（`@Cron('0 * * * *')` 每小时），无需额外配置。
dev 手动触发：`POST /api/v1/job-posts/expire-now`（需登录，prod 禁止）。

## 小程序

微信开发者工具打开 `apps/user-miniprogram`，`project.config.json` appid 已配 `wx6d60329e0114a09a`。
生产：小程序后台配服务器域名（request: https://yourdomain.com/api/v1；socket: wss://yourdomain.com/ws）。

## 常见问题

- **GitHub push 超时**：本机到 GitHub 网络不稳，多重试或走代理。
- **Docker Desktop 未运行**：`"/c/Program Files/Docker/Docker/Docker Desktop.exe"` 启动。
- **prisma migrate 非交互**：用 `migrate diff --script` + `migrate deploy`（见改动记录）。
