## 一、需求与背景

`2859e32 feat(circle)` 已落地**圈子（Community）概念 + 广场页重构**的后端与广场基础 UI。本次补齐圈子**交互闭环**，对照用户提供的 8 张参考截图（**内容搜索页除外**，明确要求非 1:1）逐页复刻：

1. **加入圈子页**（未加入圈子的用户进广场先展示）
2. **创建圈子页**（LOGO + 名称 + 类型 + 所在地区 + 所在地点 + 简介）
3. **圈子切换页**（广场搜索栏左侧切换按钮打开）
4. **圈子广场页**（左侧类型列表 + 右侧圈子列表）
5. **圈子搜索页**（历史 + 结果）
6. **内容搜索页**（3 tab 表白墙 / 树洞 / 兼职，去「圈友」）

同时引入**行为变更**：去掉默认圈子 `cm_default` 的惰性自动加入——否则加入页永不出现、退出圈子会被立即重新自动加入。

## 二、已确认决策

| 决策点 | 结论 |
|---|---|
| 广场菜单 | **广场 tab 本身**，非独立菜单页 |
| 切换入口 | 广场顶部搜索栏**左侧**切换按钮 → 圈子切换页 |
| 圈子类型 | 自定义分类 `校园 / 兴趣 / 生活 / 兼职`；创建圈子**表单内选类型**（必选），广场左侧按此过滤 |
| 创建表单 | LOGO + 名称 + 类型（必选）+ **所在地区** + **所在地点** + 简介；region/location 为纯展示字符串，不做 POI 校验 |
| 行为变更 | 去掉 cm_default 惰性自动加入：未加入 → `GET /community/active` 返回 `null` → 广场 onShow 引导加入页；**写路径抛 80014「请先加入圈子」**；**读路径兜底 `DEFAULT_COMMUNITY_ID`（cm_default）** |
| 点圈子跳转 | 广场 / 圈子搜索点圈子 → 切换当前圈子 + `wx.switchTab` 回广场 tab（广场是 tabBar 左一） |
| 内容搜索 | 3 tab 表白墙 / 树洞 / 兼职，均按当前圈子作用域搜索 |

## 三、交付内容

### 3.1 数据模型（迁移 `20260813000000_community_category_region`，ADD-only）

- `Community` 加三字段：`category String @default("校园")`、`region String?`（所在地区）、`location String?`（所在地点）。
- 存量回填：`cm_default` → `category=校园`、region/location=null，迁移后 `category SET NOT NULL`。
- `prisma/seed.ts`：默认圈补 category/region/location；新增 4 个带类型 + 地区 + 地点 + 展示用 memberCount 的 seed 圈子：`cm_seed_life`（生活）、`cm_seed_study`（校园）、`cm_seed_esports`（兴趣）、`cm_seed_parttime`（兼职），让加入页 / 广场有真实观感。

### 3.2 后端接口（路由前缀 `/api/v1`）

| 端点 | 方法 | 说明 | 错误码 |
|---|---|---|---|
| `/community/list?category=` | GET | 全部 ACTIVE 圈子 + 当前用户 isMember/myRole；可选 category 过滤（广场左侧分类） | — |
| `/community/search?keyword=` | GET | 名称 `contains insensitive`，limit 20（圈子搜索页） | — |
| `/community/mine` | GET | 我的圈子 + 当前 activeId | — |
| `/community/active` | GET | 当前圈子详情；**未加入返回 `data: null`** | — |
| `/community/:id` | GET | 圈子详情（含 isMember） | — |
| `/community` | POST | 创建圈子，**3/min 限流**（API 规范 §8）；`CreateCommunityDto` 校验 | 400 校验失败 |
| `/community/:id/join` | POST | 加入圈子并置为当前 | 10003 圈主退出拒（仅 leave）/ 其他 |
| `/community/:id/leave` | POST | 退出圈子，清空 active | 10003 圈主不可退出 |
| `/community/switch` | POST | 切换当前圈子（须已是成员 + 圈子 ACTIVE） | — |

**写路径错误码**：`80014`「请先加入圈子」（HTTP 403）——发帖 / 发树洞帖 / 发岗等写入口在未加入任何圈子时抛出（`getActiveCommunityId` 单真相源，不再惰性自动加入）。

**读路径兜底**：`resolveFeedCommunityId` 缺省回退 `DEFAULT_COMMUNITY_ID`（cm_default）——`square/feed|today-hit|banners`、`confession/feed`、`treehole/posts`、`job-posts` 缺省 communityId 均不抛错，未加入也可浏览默认圈。

**内容搜索三 tab 数据源**（均按当前圈子作用域）：

| tab | 端点 | 改动 |
|---|---|---|
| 表白墙 | `GET /posts/search?q=&communityId=` | `searchPosts` 加 communityId 过滤 |
| 树洞 | `GET /treehole/posts?keyword=&communityId=` | `listPosts` 加 keyword（content contains），保持 APPROVED + 可见性 / AnonBlock 过滤 |
| 兼职 | `GET /job-posts?keyword=&communityId=` | 既有能力，直接复用 |

### 3.3 前端（`apps/user-miniprogram`，.ts 源码）

**services / 全局**
- `services/community.ts`：`CommunityVo` 加 `category/region/location`；新增 `searchCommunities(keyword)`、`listCommunities(category?)`；`getActiveCommunity(): Promise<CommunityVo | null>`（可空）。
- `services/confession.ts`：`searchPosts(q, limit?, communityId?)` 透传 communityId。
- `services/treehole.ts`：`listPosts` 透传 keyword。
- `app.ts`：globalData 加 `joinGate`（防加入页重复弹，返回广场不无限跳转）；`getActiveCommunity()` 返回 null 时不写 globalData。
- `app.json`：注册 `community/join`、`community/plaza`、`community/search`、`content-search` 四新页。

**页面**
- `pages/square/index`：topbar 搜索栏**左侧加圈子切换按钮**（当前圈 LOGO + 名称，`bindtap="goSwitch"`）；`onShow` 检测 active=null → `navigateTo` 加入页（joinGate 防循环）+ 显示「未加入圈子」空态；`goSearch` 改指内容搜索页。
- `pages/community/list/index`（**改造为圈子切换页**）：当前圈子头卡（大 LOGO + 名称 + 动态/成员数）+ 右上角「···」→ `showActionSheet` 底部菜单「退出圈子」（圈主 leave 被 10003 拒则 toast）；「我的圈子」列表 + 圈子广场 / 搜索圈子 / 创建圈子入口；`onLoad?id` 支持预览非成员圈子（标题旁「加入」按钮）。
- `pages/community/join/index`（**新增**）：顶部「创建圈子」主按钮 + 圈子卡片列表（LOGO/首字占位 + 名称 + 成员数）；点卡片 → `joinCommunity(id)` + 写 active + `switchTab` 回广场。
- `pages/community/plaza/index`（**新增**）：左侧类型列表（全部 + 校园/兴趣/生活/兼职，前端硬编码）+ 右侧该类型圈子列表；成员圈子点卡 → 切换 + `switchTab` 回广场；非成员卡片内「加入」按钮。
- `pages/community/search/index`（**新增**）：搜索栏 + 历史搜索 chips（复用 `utils/search-history`）+ 结果列表；成员 → 切换回广场，非成员 → 加入回广场。
- `pages/content-search/index`（**新增**）：3 tab 表白墙 / 树洞 / 兼职 + 历史 chips + 分页结果；骨架抄 `pages/confession-search`，去「圈友」。
- `pages/community/create/index`（**改造**）：加**类型 chips**（校园/兴趣/生活/兼职，必选）+ **所在地区** + **所在地点** + 简介；提交带 `category/region/location`。

## 七、潜在隐患

1. 内容搜索树洞 tab 需 anonToken 前置初始化；无 token 时**静默** `getAnonymousToken`（与树洞详情「引导不静默」策略不一致，本期为搜索可用性妥协，待统一）。
2. 创建圈子 region/location 为纯展示字符串，未做 POI 校验；地区 / 地点拼写自由输入。
3. leave 清空 active 后用户停留在任意内容 tab 仍可浏览默认圈（读路径兜底），需用户主动加入或回广场引导；符合设计预期但存在「未加入却见内容」观感。
4. 圈子广场 / 搜索列表一次性拉取（listPublic/search 无分页），圈子多时首屏压力；后续可按需加分页。
5. 切换页「···」仅退出圈子一项，退出后回广场 onShow 会再进加入页（joinGate 已在加入流程重置）；圈主退出被 10003 拒，前端 toast 提示。
6. seed 圈子（cm_seed_*）的 memberCount 为展示用假值（无真实成员行），供加入页 / 广场有真实观感；cm_default 已回正为真实成员数（7）。`smoke-square-hybrid-contract` 每次运行会重建 `mock_smoke_sh` 测试用户（openid 幂等），建议后续在该脚本内自行清理。
