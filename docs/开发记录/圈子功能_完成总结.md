## 1. 功能目标

用户端广场从「推荐/最新 2 tab 混合流」升级为**真圈子（Community）**概念：

- 用户可**加入圈子 / 创建圈子 / 切换圈子**
- 圈子内承载 **表白墙 / 树洞 / 兼职** 三类内容，**三类都按圈子隔离**
- 广场页按目标 UI 一比一改造：
  1. 圈子头卡：LOGO + 名称 + 动态数 + 成员数
  2. 广告位轮播图（Banner 管理模型）
  3. 今日上头：**近24h 浏览量 Top10** 表白墙帖 + 树洞帖，横向滚动
  4. 4 tab：**圈子动态**（表白墙+树洞+兼职混合流）/ 表白墙 / 树洞 / 兼职
- 本次不止 UI，后台接口同步改造

## 2. 用户确认的关键决策

| 决策点 | 结论 |
|---|---|
| 曝光度 | **仅付费推广（`boostUntil`）前置**，不引入浏览量/点赞/评论加权综合分 |
| 内容隔离 | 表白墙 / 树洞 / 兼职 **三类都按圈子隔离**（均加 `communityId`） |
| 广告位 | 新建 **Banner 管理模型** + 管理端 CRUD，先 seed 占位图 |
| 存量 5 个 `Circle` | **保留为表白墙发帖分类，不算圈子**（圈子用新模型承载） |
| 今日上头口径 | **近24h 浏览量**（用户修正，非累计浏览量） |

## 3. 数据模型 + 迁移

`apps/server/prisma/schema.prisma` 新增 4 个模型，迁移 `20260812000000_community_circle`（ADD-only + 存量回填 + seed）：

| 模型 | 表 | 用途 |
|---|---|---|
| `Community` | `communities` | 圈子：name / logo / description / ownerId / status / memberCount / postCount |
| `CommunityMember` | `community_members` | 成员（communityId+userId 唯一，role OWNER/ADMIN/MEMBER） |
| `Banner` | `banners` | 广告位（communityId 空 = 全局轮播，sortOrder / status） |
| `ContentView` | `content_views` | 浏览量去重（targetType+targetId+viewerKey+hourBucket 唯一） |

现有模型加字段：

- `Post` / `AnonymousPost` / `JobPost` → `communityId`（必填，存量回填默认圈 `cm_default`）
- `User` → `activeCommunityId`（当前圈子，每用户一个）

迁移动作：

- 默认圈子「综合大学」`cm_default`（显式 id，供回填/惰性加入引用）
- 存量 posts / anonymous_posts / job_posts 全部回填 `cm_default`
- 存量用户全部加入默认圈并置 active（memberCount 同步）
- seed 占位 Banner（`cm_default` 2 条 + 全局 1 条，mock 占位图）

## 4. 后端改动

### 4.1 新模块 `src/modules/community/`（@Global）

- **圈子 CRUD / 成员**：`GET /community/list|mine|active|:id`、`POST /community`（3/min 限流 + 内容审核）、`POST /community/:id/join|leave`、`POST /community/switch`
- **当前圈子**：`getActiveCommunityId(uid)` 惰性确保（默认圈无则自动加入 + 置 active），是发帖/发岗的单真相源
- **浏览量**：`recordContentView(type, id, viewerKey)` 去重记录（P2002 跳过）
- **今日上头**：`getTodayHot(communityId, limit)` — `$queryRaw` 聚合近24h `content_views`，JOIN 目标表过滤 communityId + status + 圈子 ACTIVE
- 错误码段 8xxxx 圈子段（80010 圈子不存在 / 80011 禁用 / 80012 已加入 / 80013 未加入 / 80015 无权）

### 4.2 三类内容圈属 + 浏览量埋点

| 模块 | 改动 |
|---|---|
| confession | createPost 写入 active community + `postCount++`；feed 支持 `communityId`（cache key 分桶 + 禁用圈不可见）；`GET /posts/:id` 浏览量埋点（viewer=uid）；deletePost `postCount--` |
| treehole | createPost 圈属（`AnonymousProfile.anonId → userId → active`，响应仍只含 anonId）；listPosts 支持 `communityId`；`GET /treehole/posts/:id` 浏览量埋点（viewer=**anonId**，红线） |
| job | createPost 支持 `communityId`（校验 ACTIVE，兜底 active/default）；listPosts 支持 `communityId` |

### 4.3 广场数据（扩展 `src/modules/square/`）

- `GET /square/feed`：union 增 `{ kind: 'job_post'; data: JobPostVo }`；`communityId` 作用域（缺省取当前圈子）；boost 前置不变；AnonBlock 隔离不变
- `GET /square/today-hit`：近24h 浏览量 TopN（跨表白墙帖 + 树洞帖，附 viewCount）
- `GET /square/banners`：圈子 + 全局 Banner（sortOrder asc）
- 表白墙 / 树洞 / 兼职 tab 分别复用 `/posts/feed` / `/treehole/posts` / `/job-posts` 的 `communityId` 过滤

### 4.4 管理端（`src/modules/admin/`）

- 圈子：`GET /admin/communities`、`POST /admin/communities/:id/disable|enable`（disable 清表白墙 feed 缓存，内容即时隐藏）
