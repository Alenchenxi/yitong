## 2026-07-12 · feat/rate-limit 接口限流（P1）

**发生时间**：2026-07-12 14:58 +0800
**状态**：已审查（typecheck + 空上下文子代理 smoke 全过，含 429 实际触发验证）
**commit**：未提交（待 squash 合并 feat/rate-limit）

### 改动概要
P1 第一项：接口限流。@nestjs/throttler 全局 100 req/min + 敏感接口 @Throttle 覆盖（wx-login/refresh 5/min，发帖/评论 5/min，匹配 10/min，上传 10/min）。429 -> 业务码 90001 + Retry-After 头（API 规范 §8）。

### 修改文件
- `apps/server/src/app.module.ts` - `ThrottlerModule.forRoot([{ ttl: 60_000, limit: 100 }])` + `ThrottlerGuard` 作为 APP_GUARD（先于 JwtAuthGuard）
- `apps/server/src/common/filters/all-exceptions.filter.ts` - 429 -> `{ code: 90001, message: '请求过于频繁，请稍后重试', traceId }` + `Retry-After: 60` 头
- `apps/server/src/modules/auth/auth.controller.ts` - wx-login + refresh `@Throttle({ default: { ttl: 60_000, limit: 5 } })`
- `apps/server/src/modules/confession/confession.controller.ts` - createPost + createComment @Throttle 5/min
- `apps/server/src/modules/treehole/treehole.controller.ts` - createPost @Throttle 5/min + match @Throttle 10/min
- `apps/server/src/modules/upload/upload.controller.ts` - upload @Throttle 10/min
- `apps/server/package.json` + `pnpm-lock.yaml` - 加 `@nestjs/throttler` ^6.5.0

### 完成的工作
- ✅ 全局限流：每 IP 100 req/min（ThrottlerGuard 作为 APP_GUARD，先于 JwtAuthGuard）
- ✅ 敏感接口覆盖：wx-login/refresh 5/min、发帖/评论 5/min、匹配 10/min、上传 10/min
- ✅ 429 响应：`{ code: 90001, message: '请求过于频繁，请稍后重试', traceId }` + `Retry-After: 60` 头
- ✅ 空上下文子代理测试全过：连发 6 次 wx-login -> 前5次 201(code:0)，第6次 429(code:90001 + Retry-After)；其他接口（/auth/me、/circles、/posts/feed）不受影响
- typecheck 通过

### 潜在隐患
1. **内存限流**：ThrottlerGuard 默认内存存储，多实例不共享；生产多实例需换 Redis 存储（@nestjs/throttler-storage-redis）。
2. **全局 100/min 可能偏紧**：小程序一次页面加载可能并发多个请求；如误触可调高。
3. **@Public 接口也被限流**：ThrottlerGuard 不区分 @Public，wx-login/refresh/notify 等白名单接口也限流（合理，防刷）。
4. **无 IP 白名单**：未排除内网/管理 IP；生产可加 trusted proxy 配置。
5. **限流粒度按 IP**：NAT 后多用户共享 IP 可能误触；生产需配 `X-Forwarded-For`（nginx 已设）。

### 后续待做工作 / 方向
1. 提交 + squash 合并 + push。
2. 生产多实例：换 `@nestjs/throttler-storage-redis`。
3. P1 下一项：`feat/notifications`（站内通知）。

7. **未运行时验证**：仅 typecheck 通过；需 PostgreSQL + 首次 `prisma migrate` 后才能跑通 wx-login。
8. **role 单值**：`User.role` 单字段，同一自然人既为学生又为商家时无法兼表；后续可能改多角色或经 Merchant 关联表达。
