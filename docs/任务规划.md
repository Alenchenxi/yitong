# 燚桐功能任务规划

> 本文用于把 `docs/功能规划.md` 拆成可执行任务，并记录当前完成状态。后续每完成一个任务，必须同步把本文对应状态从“待实现”改为“已完成”，并在 `docs/开发记录/改动记录.md` 追加记录。

## 0. 状态规则

- **已完成**：当前代码已有用户入口、后端数据/API、权限校验、基础异常处理，并可形成可用闭环。
- **待实现**：未实现，或只有局部基础能力但未达到功能规划要求。
- 本文只使用“已完成 / 待实现”两种状态。已有基础但不完整的任务仍标“待实现”，备注说明已有部分。
- 不做项不进入任务表，避免后续误实现。

## 1. 当前基线判断

当前代码已具备的基础能力：
- 表白墙：基础图文发布、列表、圈子列表、详情、点赞、一级评论、举报、我的发布。
- 树洞：匿名身份、匿名图文发布、广场列表、详情、点赞、随机匹配、匹配后基础文字聊天、单一派对房。
- 兼职：商家入驻与审核、岗位发布、付费发布基础流、岗位列表/详情、报名、报名状态流、学生评价商家、商家订单与退款基础流。
- 通用：图片上传、收藏、消息中心、微信订阅消息关键提醒、基础后台审核队列、用户封禁基础能力。

当前主要缺口：
- UI 仍未按 `docs/UI设计规范.md` 完成统一平台化重构。
- 表白墙缺关注流、热榜/今日上头、多级评论、关注粉丝、搜索、草稿、定时、编辑删除等完整社区能力。
- 树洞缺画像问卷、规则匹配度、语音消息、群聊广场和真实群聊管理。
- 兼职缺岗位结构化字段、完整筛选、简历、取消报名、未录用、商家评价学生、客服工单、数据看板等。

- 不得为了快速上线把“待实现”任务伪装成“已完成”。
